# 2048 ADB Bot

Нативный бот для мобильной игры **2048**. Телефон подключается к компьютеру по
USB, бот делает скриншот через `adb`, распознаёт доску, считает лучший ход
**экспектимаксом** и отправляет обычный свайп через штатный ввод Android
(`input swipe`).

Приложение видит только **обычные жесты пальцем** — нет ни модификации apk, ни
рута, ни инструментации. Между ходами делаются «плавающие» минимальные паузы, а
у каждого свайпа рандомизируются точка старта, длина, угол и длительность, чтобы
ввод не выглядел механическим.

## Как это работает

```
adb screencap ──▶ vision (доска 4×4) ──▶ solver (expectimax) ──▶ humanize ──▶ adb input swipe
      ▲                                                                              │
      └──────────────────────── читаем экран заново после каждого хода ◀────────────┘
```

Бот **не** симулирует игру вслепую: каждое решение принимается по свежему
скриншоту, поэтому случайные новые плитки всегда учтены. Кнопка «отмена хода» не
нужна. При game over бот жмёт «Нова гра» и начинает следующую попытку —
столько попыток, сколько задано в конфиге, с сохранением лучшего результата.

## Что нужно

1. **Телефон**: включить *Настройки → Для разработчиков → Отладка по USB*,
   подключить кабелем, разрешить отладку с этого компьютера.
2. **ADB** (Android platform-tools) в `PATH`. Проверка: `adb devices` должен
   показывать телефон как `device`.
3. **Python 3.9+** и зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Для распознавания цифр (`reader: ocr`) — бинарь **tesseract**:
   ```bash
   sudo apt install tesseract-ocr        # Linux
   brew install tesseract                # macOS
   ```
   Либо используйте `reader: color` (без tesseract, см. калибровку ниже).

## Настройка (калибровка) — обязательный шаг один раз

Координаты в `config.yaml` даны для эталонного экрана 1080×2400 и почти наверняка
нужно подогнать под ваш телефон.

1. Откройте игру, положите телефон, запустите:
   ```bash
   python calibrate.py            # снимет экран и сохранит overlay.png
   ```
2. Откройте `overlay.png`. Красные точки должны попадать в центр каждой из 16
   клеток, зелёные квадраты — не вылезать за клетку. Если нет — правьте блок
   `geometry` в `config.yaml`:
   - `first_center_x/y` — центр верхней-левой клетки,
   - `pitch_x/y` — расстояние между центрами соседних клеток,
   - `cell_size` — размер пробы внутри клетки.
3. Проверьте распознавание:
   ```bash
   python main.py --dry-run       # печатает найденную доску, без свайпов
   ```
   Числа должны совпадать с экраном.
4. Уточните кнопку «Нова гра» (`game.new_game_button`) — координаты в разрешении
   скриншота.

### Вариант без tesseract: `reader: color`

Цвет фона плитки в 2048 фиксирован под каждое значение. Выучите палитру один раз:

```bash
python calibrate.py --learn-colors     # печатает средний RGB каждой занятой клетки
```

Сопоставьте RGB значениям на экране и впишите в `vision.color_palette`
(`config.yaml`), затем поставьте `vision.reader: color`.

## Запуск

```bash
python main.py                 # играть по config.yaml (max_tries игр)
python main.py --tries 100     # больше попыток за прогон
python main.py --seed 7        # воспроизводимый рандом пауз/джиттера
```

Каждую игру бот печатает строку с максимальной плиткой и числом ходов, в конце —
лучший результат. Прервать — `Ctrl-C`.

## Настройки, влияющие на силу и «человечность»

`config.yaml`:

- `solver.max_depth` — глубина поиска. Больше = сильнее, но медленнее на ход.
  На открытой доске глубина авто-снижается ради скорости.
- `spawn_distribution` — вероятности новых плиток. Стандарт: `{2: 0.9, 4: 0.1}`.
- `timing.*` — паузы между ходами (минимальные + редкие «раздумья»).
- `swipe.*` — джиттер точки старта, длины, угла и длительности свайпа.

## Проверка движка без телефона

Логика игры и ИИ тестируются полностью headless:

```bash
python -m pytest tests/ -q         # юнит-тесты механики и солвера
python tests/test_solver.py 20     # 20 полных игр самоигрой + статистика
```

На эталонных прогонах (стандартный спавн 2/4) солвер стабильно доходит до
2048–4096.

## Замечания

- Это одиночная головоломка; бот автоматизирует только вашу собственную игру.
- Скорость ограничена в основном раунд-трипом скриншота (~100–300 мс на ход).
- Если ход на экране ничего не поменял, бот считает его невозможным и берёт
  следующий по силе; несколько подряд таких = конец игры и новая попытка.
```

## Структура

```
config.yaml          параметры (геометрия, тайминги, солвер, кнопки)
main.py              точка входа
calibrate.py         подгонка сетки и обучение цветовой палитры
src/adb.py           обёртка над adb: screencap / swipe / tap
src/vision.py        скриншот → матрица 4×4 (OCR или по цвету)
src/solver.py        механика 2048 + экспектимакс
src/humanize.py      плавающие паузы и джиттер свайпов
src/bot.py           главный цикл read → think → swipe
tests/test_solver.py тесты + бенчмарк самоигрой
```
